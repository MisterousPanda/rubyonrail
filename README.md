# Ruby / Rails / Omarchy

An unofficial homage to DHH: the beauty of Ruby, the architecture of Rails, how to deploy a Rails app (and whether Vercel hosts one), plus Omarchy — with Cursor and Hermes subpages.

```bash
npm install
npm run dev
```

Production is this Next.js app on Vercel. A full Rails monolith is a different deploy path — see `/deploy`.
